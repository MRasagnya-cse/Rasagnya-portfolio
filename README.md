## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6+
- Bootstrap Icons

## Assignment Requirements Covered
- Semantic HTML5 sections: Home, About, Education, Skills, Projects, Achievements and Contact
- Responsive CSS3 layout with media queries
- Bootstrap navbar, grid, cards, buttons, table, forms and alerts
- JavaScript theme switching
- Client-side form validation with dynamic success/error messages
- Back-to-top interaction
- Accessible labels and responsive design
